### [Principle] D1 — QuickJS TLA settlement + out-of-scope job pumping (never Promise::finish)
`Promise::finish()` spins only the job queue -> "dead lock" when the await needs worker threads (fetch/TLS); `execute_pending_job()` inside an active `Context::with` re-enters the RefCell and panics. Pattern: evaluate WITHOUT finish; JS glue writes settlement flags to `globalThis`; pump fetch/HTTP/TLS drains + jobs ONLY BETWEEN scopes; idle-grace detects deadlock. Uncaught errors keep `name + ": " + message` as FIRST line (stack-first output lost gate regex `/boom_test/`). NEVER wire `.then` from Rust via Function-value `.call(rust_fn)` ("Exception generated by QuickJS" — detached `this`): pass `promise.into_value()` into JS glue. Evidence: MODULE_GLUE/settle_module, cz-runner main.rs; Phase 2/8A/8B/8C gates green.
